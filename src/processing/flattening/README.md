# Flattening Service

## Concept
Transforms semi-structured input data into a flattened representation for downstream processing.

## Responsibilities
- Define and coordinate the flattening operation.
- Preserve the structural information required by downstream profiling.

## Input and output contracts
Input and output schemas are not defined yet. Document them in code when the service is implemented.

## Notes
The Databricks Asset Bundle is configured locally under `../infrastructure/`. No flattening job is configured until the service has an executable entry point.
